# Contributing

EES Genesis v1.0.0 is the founding public implementation of the Engineering
Experience System.

Before proposing a change:

1. Open an issue describing the problem, expected behavior, and affected area.
2. Keep changes focused and preserve accessibility and reduced-motion support.
3. Run `npm run build` and `npm run verify:production`.
4. Include screenshots or a short recording for visible interaction changes.

Public contributions should improve clarity, reliability, accessibility,
performance, documentation, or engineering value.
